# FindIt – Lost and Found Portal

## About the Project
FindIt is a web-based Lost and Found Portal designed to help people report lost belongings and find items reported by other users.

## Features
- User registration and login
- User dashboard
- Report lost items
- Report found items
- Browse reported items
- Item details
- User profiles
- Messaging and notifications
- Manage personal reports

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap (if used)

## Requirements
- XAMPP or compatible PHP hosting
- PHP
- MySQL
- Web browser

## Local Installation
1. Download or clone this repository.
2. Copy the project folder into `xampp/htdocs/`.
3. Start Apache and MySQL using XAMPP.
4. Open phpMyAdmin.
5. Create a database named `findit_db`.
6. Import the provided SQL database file.
7. Configure your local database credentials.
8. Open `http://localhost/findit/`.
